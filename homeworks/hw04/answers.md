# Ответы на короткие вопросы

1. **Что означает форма `(13, 7)`?**
   13 строк — моменты времени (по `time_h`), 7 столбцов — наблюдательные расстояния (по `radius_m`). Элемент `[i, j]` — давление в момент `time_h[i]` на расстоянии `radius_m[j]`.

2. **Зачем перед построением используется `.T`?**
   Matplotlib для `pcolormesh(x, y, C)` и `contour(x, y, C)` ожидает `C.shape == (len(y), len(x))`. У нас `x = time_h (13)`, `y = radius_m (7)`, поэтому `C` должен быть `(7, 13)`. `.T` меняет оси местами, значения при этом не меняются — меняется только согласование формы с осями.

3. **Что показывает одна цветная ячейка `pcolormesh`?**
   Значение поля в узле/ячейке исходной сетки — то есть давление в конкретный момент времени на конкретном радиусе. Границы ячеек показывают разрешение данных.

4. **Что обозначает область между уровнями `contourf`?**
   Множество точек, где значение поля лежит между двумя соседними уровнями; все они закрашены одним цветом. Граница области — изолиния соответствующего уровня.

5. **Что соединяет изолиния?**
   Точки, в которых отображаемая величина имеет одинаковое значение (уровень).

6. **Почему контуры могут выглядеть гладкими на редкой сетке?**
   Положение контура вычисляется линейной интерполяцией между узлами — Matplotlib «достраивает» гладкую линию между редкими отсчётами. Новых измерений при этом не появляется.

7. **Почему для сравнения нужны одинаковые `vmin`, `vmax` и цветовая карта?**
   Иначе одинаковое число будет иметь разный цвет на двух панелях, и визуальное сравнение станет некорректным.

8. **Что изменится при увеличении количества уровней?**
   `contourf` даст более мелкое разбиение диапазона — градиент выглядит плавнее, но появляется больше областей и изолиний; слишком много уровней делает рисунок нечитаемым.

9. **Почему гладкая картинка не означает высокую точность данных?**
   Гладкость — результат интерполяции между узлами сетки, а не дополнительных измерений. Реальное разрешение данных остаётся таким же, как исходная сетка 13×7.
