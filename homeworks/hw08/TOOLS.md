# Памятка по инструментам Inkscape

Начните с одной стрелки и подписи. Затем постройте один повторяющийся элемент, например опору или стрелку профиля. Освоенные действия повторяйте в обеих схемах.

| Что сделать | Где искать и как действовать |
| --- | --- |
| Выделить и переместить | Инструмент выделения; щёлкните объект, перетащите его или задайте координаты на панели |
| Нарисовать прямоугольник/эллипс | Соответствующий инструмент на боковой панели; параметры размера доступны сверху |
| Сделать ломаную | Перо Безье: щёлкайте в местах углов; Enter завершает открытую линию, щелчок по первому узлу замыкает контур |
| Сделать плавный участок | Пером нажмите и потяните для появления ручек; редактором узлов выделите узел и измените ручки |
| Убрать заливку | Выделите контур → «Заливка и обводка» → «Заливка» → нет заливки |
| Сделать стрелку | Нарисуйте открытую линию; в «Заливка и обводка → Стиль обводки» выберите конечный маркер. Для размера задайте начальный и конечный |
| Нарисовать момент/угол | Изогнутая открытая линия; для момента добавьте маркер на одном конце, для угла оставьте дугу без наконечника |
| Сделать пунктир | В стиле обводки выберите пунктирный рисунок и подходящую толщину |
| Повторить элемент | Дублируйте выделение; переместите копию. Несколько копий выделите и распределите через «Выровнять и распределить» |
| Повернуть/отразить | Используйте команды преобразований или кнопки панели; проверьте, что направление силы осталось как на образце |
| Выровнять подписи | Выделите несколько объектов, выберите опорный объект/страницу в «Относительно» и нужную команду выравнивания |
| Совместить линии точно | Включите привязки, разрешите привязку к узлам; подведите конец линии к нужному узлу |
| Сгруппировать | Выделите части, например стрелку и подпись → «Объект → Сгруппировать» |
| Убрать заливку назад | Выделите залитый объект и используйте команду опускания в порядке объектов; контуры и текст оставьте выше |
| Ввести индекс | Инструментом текста выделите символ индекса и примените нижний индекс на панели текста. Основную букву оставьте обычной |
| Ввести греческую букву | Вставьте нужный символ, например α, θ, ρ или φ, и проверьте его отображение выбранным шрифтом |
| Заблокировать подложку | Найдите слой образца в «Слои и объекты», включите замок. Перед экспортом выключите его видимость |
| Сохранить PDF | Сохраните основной SVG, затем сохраните копию PDF; после этого продолжайте редактирование SVG |
| Экспортировать PNG | Откройте экспорт, выберите область «Страница», задайте 200 dpi, проверьте путь и экспортируйте |

Расположение кнопок зависит от версии. Наведите курсор на значок и прочитайте подсказку. Не нужно учить сочетания клавиш наизусть: нужно уметь найти и применить операцию.
