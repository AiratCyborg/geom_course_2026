# Ответы на вопросы

1. **Чем DataFrame отличается от массива NumPy?**
   DataFrame — двумерная таблица с именованными столбцами и индексом строк, может содержать разные типы данных в разных столбцах. Массив NumPy — однородная по типу структура без имён столбцов, ориентированная на числовые вычисления.

2. **Что означают две величины в `shape` массива `(13, 2)`?**
   Первая величина — число строк (13), вторая — число столбцов (2). Всего 26 элементов.

3. **Почему `pressure * 1_000_000` не требует цикла `for`?**
   Pandas/NumPy выполняют векторизованные операции: действие применяется ко всем элементам столбца сразу на уровне C-кода, без явного цикла Python.

4. **Что выбирает срез `array[::2]`?**
   Каждый второй элемент массива, начиная с нулевого индекса: индексы 0, 2, 4, …

5. **Что содержится в логической маске?**
   Массив значений `True`/`False` той же длины, что и исходный массив; `True` соответствует элементам, удовлетворяющим условию (например, `pressure < pressure.mean()`).

6. **Зачем после сохранения загружать массив обратно?**
   Чтобы убедиться, что файл записан корректно и данные при загрузке полностью совпадают с исходными (проверка через `numpy.allclose`).

7. **Какие файлы являются исходными, а какие создаются программой?**
   Исходные: `data/raw/hw01/wells.csv`, `layers.xlsx`, `pumping_test.txt` (создаются генератором `generate_data.py`). Создаются программой: `data/processed/hw01/wells_clean.csv`, `table_summary.xlsx`, `pressure_matrix.npy`, `pressure_cube.npz`, `exports/hw01/results.txt`.
