# ДЗ №7. Нестационарное поле в 2D и 3D

**Темы:** координатная сетка, `meshgrid`, `plot_surface`, `plot_wireframe`, камера, маска, сравнение эпох.

## Зачем это задание

В ДЗ №6 вы исследовали изменяющееся температурное поле в ParaView. Теперь представьте те же данные в Matplotlib и проверьте, что изображение соответствует массивам. Объяснять причины нагрева или знать уравнения теплопроводности не требуется. Все выводы опирайте на числа, координаты и свойства изображения.

Поле нестационарное: для каждой эпохи сохранена своя таблица температур и своя маска пород. Время выбирает кадр. Три оси поверхности обозначают горизонтальную координату x, вертикальную координату модели z и температуру T. Это график функции T(x, z), а не объёмная геометрия бассейна.

## 1. Подготовьтесь

Обновите fork через Sync fork, затем выполните `git pull` из корня своей копии. Используйте окружение курса с NumPy и Matplotlib. Новые библиотеки не нужны.

Файл `homeworks/hw07/data/thermal_history.npz` содержит подмножество исходного `homeworks/hw06/data/result.h5`, без интерполяции и пересчёта значений:

| Ключ | Форма | Смысл |
| --- | --- | --- |
| `x_m` | (46,) | центры ячеек по горизонтали, м |
| `z_m` | (112,) | абсолютная вертикальная координата центров, м |
| `ages_ma` | (18,) | возраст, млн лет до настоящего |
| `temperature_C` | (18, 112, 46) | температура, °C |
| `active` | (18, 112, 46) | 1 — породы, 0 — вне области |

Возраст уменьшается от 200 до 0 Ma. Оси x и z возрастают. Вне пород температуры равны NaN. Координата z не равна расстоянию под текущей поверхностью.

Загрузите файл через `np.load(..., allow_pickle=False)`. Пути вычисляйте относительно расположения `solution.py`, чтобы запуск из другой папки также работал.

## 2. Выберите две эпохи и проверьте данные

Выберите две разные эпохи из `ages_ma`. Хотя бы одна должна быть промежуточной: нельзя ограничиться парой 200 и 0 Ma. Запишите выбранные возраста и индексы в `answers.md`. Сделайте возможность сменить оба индекса в одном месте программы.

Проверьте формы массивов, строгое возрастание x и z, убывание возраста, значения маски 0/1, конечность температур внутри пород и NaN вне них. Для каждой выбранной эпохи выведите число активных ячеек, минимум и максимум температуры среди них.

До построения рисунков выберите по три активные ячейки в каждой эпохе: одну с наименьшим z, одну в средней части диапазона z, одну с наибольшим z при наличии пород. Среди нескольких подходящих столбцов выберите любой. Для каждой запишите индексы `j, i`, координаты `x_m[i], z_m[j]` и температуру `temperature_C[k, j, i]`. Здесь k — индекс эпохи, j — строка по z, i — столбец по x.

Это шесть контрольных точек. Обозначьте их A, B, C для каждой эпохи. Они должны присутствовать на 2D-карте и поверхности. Сравнение опирается на значения в файле, прогноз физических процессов не нужен.

## 3. Согласуйте сетку и массив

Создайте `X, Z = np.meshgrid(x_m, z_m, indexing="xy")`. Формы X и Z должны быть `(112, 46)`, как у одного кадра температуры. Проверьте хотя бы в двух точках, что `X[j, i] == x_m[i]` и `Z[j, i] == z_m[j]`.

Объясните в ответах, почему здесь не требуется `.T`, хотя в ДЗ №4 транспонирование использовалось. Ответ подтвердите формами массивов и значением одной конкретной ячейки.

Для каждого кадра создайте отдельный массив изображения: `np.where(active[k] == 1, temperature_C[k], np.nan)`. Исходные массивы не изменяйте.

## 4. Постройте сравнение двух эпох

Сохраните `comparison.png` и `comparison.svg`: две строки по эпохам и три столбца по способам изображения.

1. **Карта:** `pcolormesh(X, Z, T, shading="nearest")`, с цветовой шкалой температуры; z увеличивается вниз. Пропорции расстояний по x и z одинаковы (`set_aspect("equal")`).
2. **Поверхность:** `plot_surface(X, Z, T, ...)`. Подписи: `x, m`, `z, m`, `Temperature, °C`. Добавьте цветовую шкалу температуры и точки A, B, C с текстовыми метками.
3. **Каркас:** `plot_wireframe(X, Z, T, rstride=1, cstride=1)`. Каркас показывает связи между соседними центрами активных ячеек. Его линии не являются границами физических ячеек.

На карте тоже отметьте A, B, C. В заголовке каждой панели укажите возраст. Для обеих эпох задайте одинаковые x/y/z-пределы 3D-осей, одинаковую камеру, пропорции блока осей и размер панелей. Температурная ось и цветовая шкала — **17–170 °C**, цветовая карта — Viridis. x и z должны охватывать всю исходную сетку. Для `plot_surface` явно задайте `rcount=len(z_m), ccount=len(x_m)`, чтобы стандартное прореживание не выбрасывало строки данных.

Пустые участки должны оставаться пустыми. Surface соединяет центры ячеек; его граница может не совпадать с внешним краем пикселей pcolormesh. Гладкость поверхности не добавляет измерений.
