# Ответы на короткие вопросы

1. **Почему моменты времени можно соединять линией?**
   Время упорядочено монотонно, между соседними замерами существует непрерывный физический процесс; линия отражает изменение давления во времени.

2. **Почему наблюдательные скважины не нужно соединять?**
   Скважины — независимые объекты, между ними нет упорядоченной связи по `radius`; линия создала бы ложное впечатление непрерывной зависимости.

3. **Когда уместна столбчатая диаграмма?**
   Когда нужно сравнить дискретные категории (здесь — падение давления по каждой скважине) по одной количественной величине.

4. **Что показывает линия внутри boxplot?**
   Медиану распределения. (Коробка — Q1–Q3, усы — 1.5·IQR, точки — выбросы.)

5. **Чем violin plot отличается от boxplot?**
   Violin дополнительно показывает форму распределения (KDE) — моду, мультимодальность; boxplot компактнее и устойчивее к малым выборкам.

6. **Почему круговая диаграмма не подходит?**
   Давления — не доли одного целого; их сумма не имеет смысла.

7. **Зачем все связанные массивы сортировать одним порядком?**
   Иначе соответствие «скважина ↔ радиус ↔ давление» нарушится, и график будет вводить в заблуждение.
